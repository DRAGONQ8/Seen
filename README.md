# سين جيم خالد — V4

لعبة مسابقات عربية أصلية لفريقين، تعمل دون إنترنت من ملف واحد. افتح **[index.html](index.html)** بعد تنزيله على الجهاز. لا حسابات، لا خدمات خارجية، ولا ملفات مطلوبة وقت اللعب.

- لوحة كلاسيكية من 36 سؤالًا: 6 فئات، 3 لكل فريق، وسؤالان مستقلان لكل قيمة 200/400/600. لوحة سريعة من 18 سؤالًا.
- افتح الخانة ← اكشف الإجابة ← اختر الأزرق أو الذهبي أو «محد جاوب صح». تُحسم النقاط والمساعدات والخانة والدور بمعاملة واحدة وتعود اللوحة فورًا. التراجع بلمسة يعكس الآثار المرتبطة ويحافظ على معرفة الحل.
- مواجهة تحدٍ تفضّل الأصعب، مواجهة بصرية تفضّل الصور المؤهلة، وتخصيص محدود وآمن للفئات والقيم والمؤقّت والسرقة والمساعدات، جميعها بالمحرك نفسه.
- بحث ومفضلة وتوزيع عشوائي للفئات، قوالب أسماء الفرق، إيقاف/استئناف، تصحيح نقاط بسجل معاملات، إعدادات الصوت والحركة وحجم الخط، ونسخ احتياطية للمقدم.
- 720 سؤالًا في 11 فئة، منها الكويت والعلوم والفضاء والمنطق. نصوص وصور وأعلام وخرائط، وترتيب، وقرائن تدريجية، وأسئلة متعددة الأجزاء ومنطقية بتحكيم كامل وواضح.

الحفظ محلي في المتصفح. عند تعذّر التخزين تستمر المباراة في الذاكرة ويظهر تنبيه لتصدير نسخة المتابعة قبل الإغلاق. عند الاسترجاع يتوقف المؤقّت حتى يستأنفه المقدم. نسخ المتابعة تحتوي الحلول وهي خاصة بالمقدم؛ Base64 ترميز وليس تشفيرًا.

## المحتوى والتحرير

الحالات الأربع هي `source-checked` (مطابقة مصدر بأدلة)، `editorial` (مراجعة تحريرية)، `pending` (معلّق)، و`disputed` (مختلف فيه). وجود رابط لا يثبت التحقق. 48 سؤالًا جديدًا طوبقت مع مصادر مؤسسية في هذه المراجعة، و24 لغزًا أصليًا راجعتها أدلة الحل. تحتفظ 155 علامة تحقق سابقة بمصدرها التاريخي؛ لم نُعِد فحصها جميعًا.

تُحفظ الأسئلة المعلقة والمختلف فيها ولا تدخل مباريات جديدة. استبعادها لا يغيّر أسئلة مباراة قديمة محفوظة بنسختها الثابتة. تفاصيل الأسئلة المستبعدة، العدّ حسب الفئة والقيمة، وحدود التحقق في [content-audit.json](content-audit.json). تحرير الأسئلة وتعطيلها واستيرادها وتصديرها من **مكتبة المقدم**، خارج المباراة النشطة. هذه أدوات مالك الملف المحلية، وليست صلاحيات خادم أو حماية للحلول من مالك الملف.

راجع [دليل التحرير](docs/CONTENT-EDITORIAL.md)، [مخطط السؤال](docs/question-schema.json)، وملفي الأدلة [للكويت](docs/kuwait-source-evidence.json) و[للعلوم](docs/science-source-evidence.json). المساعدات الخمس الموثقة علنًا متميزة عن المساعدات والقواعد المنزلية الإضافية؛ انظر [بحث القواعد](rules-research.json) و[عقد المساعدات](docs/ASSISTANCE.md).

## البناء والاختبار

يتطلب البناء Python 3 فقط. Node وPlaywright وaxe أدوات تطوير ولا تُضمّن في اللعبة.

```sh
python build.py
npm ci
npx playwright install chromium firefox
npm test
```

عند وجود Chromium مثبت محليًا، تعيّن الاختبارات مساره الافتراضي إلى `/usr/bin/chromium`؛ يمكن تغييره باستخدام `CHROMIUM_PATH`. يشغّل الاختبار الكامل خادمًا محليًا مؤقتًا. تستخدم الاختبارات أحجام شاشات ولمسًا محاكى، ولا تمثل فحصًا على أجهزة فعلية. تثبيت WebKit يتطلب مكتبات النظام المناسبة؛ يسجل التقرير عدم إتاحته صراحةً.

```sh
python content_tools.py --report content-audit.json
npm run test:unit
npm run test:browser
npm run test:a11y
npm run test:cross-browser
```

يولّد `build.py` ملف HTML بصورة حتمية من ملفات المصدر، بما فيها الخط المحلي والصور والتراخيص. لا تعدّل HTML يدويًا. لا توجد CDN أو مفاتيح API أو تحليلات استخدام. يحتفظ التحديث بحفظ الفريقين وتفضيلات العرض والمفضلة؛ تُزال بيانات اللعب القديم غير المدعوم بعد نجاح ترحيل التفضيلات فقط.

## الجودة والحدود

نتائج التنفيذ الفعلية في [validation-report.json](validation-report.json)، والتدقيق المعماري في [docs/architecture.md](docs/architecture.md). لا ندّعي تحققًا مستقلًا من كل سؤال أو اختبار أجهزة حقيقية. لم تضف مقاطع تجارية أو صوتًا للتعرّف على الأغاني؛ الأصوات الحالية مؤثرات أصلية داخل المحرك. قد تستخدم المواجهة البصرية سؤالًا نصيًا عند نقص صورة مؤهلة في الفئة والقيمة، ويعلن المحرك ذلك. ملء الشاشة بحسب دعم المتصفح؛ على iPhone يتاح العرض العادي وخيارات Safari للشاشة الرئيسية.
